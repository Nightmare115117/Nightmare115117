## `01 // ABOUT.ME`

Soy estudiante de **Ingeniería en Sistemas Computacionales**, enfocado en construir software a distintos niveles del stack: desde la API hasta el proceso que la corre.

Áreas que me interesan:

* ⚙️ Desarrollo backend
* 🌐 Redes de computadoras
* 🐧 Linux y administración de sistemas (uso Arch a diario)
* 🗄️ Sistemas de bases de datos
* 🐳 Contenedores y despliegue (Docker, GitHub Actions, k3s)
* 🔌 Sistemas embebidos
* 🧠 Arquitectura de sistemas

Me gusta entender **qué pasa debajo de la abstracción**: un request HTTP, una conexión a base de datos, un contenedor, un pod de Kubernetes.
